CASE STUDY 01: UNIVERSITY SCHOLARSHIP ALLOCATION SYSTEM (Problem 01)

Syllabus Concepts: Variables, Data Types, Conditional Statements, Lists, Tuples, Tuple Unpacking, Sorting Algorithms

1. Problem Statement

Design an automated scholarship allocation system that evaluates applicants against aggregate marks, subject-wise minimum scores, attendance percentages, and family income criteria. Rank eligible candidates and resolve ties using deterministic rules (Aggregate Marks > Lower Annual Income > Higher Attendance).

2. Objectives

1. Validate applicant eligibility against 4 strict thresholds.
2. Classify awards into Fee Waiver Tiers (100%, 75%, 50%).
3. Implement deterministic tie-breaking logic using list sorting.
4. Produce detailed allocation and funds disbursement reports.

3. Assumptions & Constraints

1. Aggregate marks >= 80.0%, minimum subject mark >= 65.0%.
2. Attendance must be at least 75.0%.
3. Annual family income must not exceed ₹3,00,000.
4. Income and marks are non-negative numeric quantities.

4. Step-by-Step Algorithm

1. Initialize eligible_candidates list.
2. For each applicant tuple (id, name, agg, min_sub, att, inc): unpack tuple.
3. Check all 4 eligibility conditions. If passed, determine fee waiver tier and append to eligible list; else record rejection reason.
4. Apply bubble sort on eligible list comparing Aggregate (desc), Income (asc), Attendance (desc).
5. Iterate through ranked list, assign rank numbers, calculate total funds, and display report.

5. Pseudocode

FUNCTION evaluate_scholarships(applicants):
    SET eligible_list = []
    FOR EACH (id, name, agg, min_sub, att, inc) IN applicants:
        IF agg >= 80 AND min_sub >= 65 AND att >= 75 AND inc <= 300000 THEN
            tier = DETERMINE_TIER(agg)
            eligible_list.APPEND([id, name, agg, inc, att, tier])
        ELSE
            PRINT rejection reason
    SORT eligible_list BY agg DESC, inc ASC, att DESC
    DISPLAY final ranked recipients and total funds
END FUNCTION

CASE STUDY 02: EMPLOYEE PAYROLL AND DEDUCTION ANALYSIS (Problem 04)

1. Problem Statement

Calculate monthly gross salary from basic pay, allowances (HRA, DA), overtime, and performance incentives. Apply progressive deductions including Provident Fund (PF), Professional Tax (PT), and annualized Income Tax (TDS) based on progressive tax slabs, producing an executive payroll statement.

2. Objectives

1. Calculate HRA, DA, overtime pay, and gross earnings.
2. Compute statutory PF (12% of basic) and slab-based Professional Tax.
3. Implement annualized progressive Income Tax slab calculations.
4. Generate net take-home pay and executive grade classification.

3. Assumptions & Constraints

1. HRA and DA are calculated as percentages of Basic Pay.
2. Overtime is paid hourly at the contract OT rate.
3. Income tax is progressive: 0% up to ₹3L, 5% up to ₹6L, 10% up to ₹9L, 15% up to ₹12L, 20% above ₹12L.

4. Step-by-Step Algorithm

1. For each employee record: unpack tuple (emp_id, name, basic, hra_pct, da_pct, ot_hrs, ot_rate, inc).
2. Gross = basic + (basic*hra_pct/100) + (basic*da_pct/100) + (ot_hrs*ot_rate) + inc.
3. Compute PF = 0.12 * basic. Compute PT from monthly gross.
4. Annualize gross (gross * 12). Compute progressive income tax across brackets. Monthly tax = annual_tax / 12.
5. Net = gross - (PF + PT + monthly_tax). Output formatted payroll row.

5. Pseudocode

FUNCTION generate_payroll(employees):
    FOR EACH emp IN employees:
        gross = basic + hra + da + overtime + incentive
        pf = 0.12 * basic
        pt = CALCULATE_PT(gross)
        annual_tax = CALCULATE_PROGRESSIVE_TAX(gross * 12)
        monthly_tax = annual_tax / 12
        net = gross - (pf + pt + monthly_tax)
        PRINT formatted salary row
END FUNCTION

"""

def generate_payroll_statement(employees):
    print("=" * 105)
    print("                      CORPORATE MONTHLY PAYROLL & SALARY STATEMENT")
    print("=" * 105)
    print(f"{'EmpID':<7} {'Name':<15} {'Basic(₹)':<10} {'Allow(₹)':<9} {'OT+Inc(₹)':<10} {'Gross(₹)':<11} {'PF(₹)':<8} {'Tax(₹)':<8} {'PT(₹)':<6} {'Net Pay(₹)':<11} {'Grade'}")
    print("-" * 105)

    total_gross_disbursed = 0.0
    total_net_disbursed = 0.0
    total_tax_collected = 0.0

    for emp in employees:
        # Tuple unpacking: emp_id, name, basic_pay, hra_percent, da_percent, ot_hours, ot_rate, incentives
        emp_id, name, basic, hra_pct, da_pct, ot_hrs, ot_rate, incentives = emp

        # 1. Allowances calculation
        hra = (basic * hra_pct) / 100.0
        da = (basic * da_pct) / 100.0
        allowances = hra + da

        # 2. Overtime & Incentives
        overtime_pay = ot_hrs * ot_rate
        variable_pay = overtime_pay + incentives

        # 3. Gross Salary
        gross_salary = basic + allowances + variable_pay
        total_gross_disbursed += gross_salary

        # 4. Progressive Deductions:
        # a) Provident Fund (PF): 12% of basic pay (capped if basic exceeds threshold)
        pf_deduction = 0.12 * basic

        # b) Professional Tax (PT): slab-based
        if gross_salary > 50000:
            pt_deduction = 250.0
        elif gross_salary > 25000:
            pt_deduction = 150.0
        else:
            pt_deduction = 0.0

        # c) Progressive Monthly Income Tax (TDS) based on annualized gross:
        annual_gross = gross_salary * 12.0
        annual_tax = 0.0

        # Tax Slabs:
        # Up to ₹3,00,000 : Nil
        # ₹3,00,001 to ₹6,00,000 : 5%
        # ₹6,00,001 to ₹9,00,000 : 10%
        # ₹9,00,001 to ₹12,00,000 : 15%
        # Above ₹12,00,000 : 20%
        if annual_gross > 1200000:
            annual_tax += (annual_gross - 1200000) * 0.20
            annual_tax += 300000 * 0.15
            annual_tax += 300000 * 0.10
            annual_tax += 300000 * 0.05
        elif annual_gross > 900000:
            annual_tax += (annual_gross - 900000) * 0.15
            annual_tax += 300000 * 0.10
            annual_tax += 300000 * 0.05
        elif annual_gross > 600000:
            annual_tax += (annual_gross - 600000) * 0.10
            annual_tax += 300000 * 0.05
        elif annual_gross > 300000:
            annual_tax += (annual_gross - 300000) * 0.05
        else:
            annual_tax = 0.0

        monthly_tax = annual_tax / 12.0
        total_tax_collected += monthly_tax

        # Total Deductions & Net Pay
        total_deductions = pf_deduction + pt_deduction + monthly_tax
        net_salary = gross_salary - total_deductions
        total_net_disbursed += net_salary

        # Pay Grade Classification
        if gross_salary >= 100000:
            grade = "Exec-A"
        elif gross_salary >= 60000:
            grade = "Sr-B"
        elif gross_salary >= 35000:
            grade = "Mid-C"
        else:
            grade = "Jr-D"

        print(f"{emp_id:<7} {name:<15} {basic:<10.2f} {allowances:<9.2f} {variable_pay:<10.2f} {gross_salary:<11.2f} {pf_deduction:<8.2f} {monthly_tax:<8.2f} {pt_deduction:<6.2f} {net_salary:<11.2f} {grade}")

    print("-" * 105)
    print(f"Total Employees Processed : {len(employees)}")
    print(f"Total Monthly Gross Payroll: ₹{total_gross_disbursed:,.2f}")
    print(f"Total Income Tax Deducted  : ₹{total_tax_collected:,.2f}")
    print(f"Total Net Salaries Paid    : ₹{total_net_disbursed:,.2f}")
    print("=" * 105)

CASE STUDY 03: ATM TRANSACTION SEQUENCE SIMULATION (Problem 13)

Syllabus Concepts: Loops, State Variables, Conditional Statements, Lists, Tuples, Transaction Validation

1. Problem Statement

Process a sequential stream of ATM banking transactions (deposits and withdrawals) against an account, enforce single-transaction caps, daily cumulative withdrawal limits, and minimum balance constraints, reject invalid operations, and generate an audit ledger.

2. Objectives

1. Maintain real-time account balance across arbitrary transaction sequences.
2. Enforce minimum balance (₹2,000) and max single withdrawal limit (₹20,000).
3. Track cumulative daily withdrawals and enforce daily ceiling (₹50,000).
4. Reject negative amounts and unsupported transaction types.

3. Assumptions & Constraints

1. Opening balance is valid and meets minimum balance requirement.
2. Transactions occur in strict chronological sequence.
3. Rejected transactions do not alter running balance or daily caps.

4. Step-by-Step Algorithm

1. Initialize balance = opening_balance, total_withdrawn = 0.
2. For each transaction (txn_id, txn_type, amount): unpack.
3. If amount <= 0: reject as invalid amount.
4. If DEPOSIT: balance += amount; log success.
5. If WITHDRAWAL: check if amount > 20,000 (single cap), or total_withdrawn + amount > 50,000 (daily cap), or balance - amount < 2,000 (min balance). If any holds, reject; else balance -= amount, total_withdrawn += amount, log success.
6. Display audit table and summary statistics.

5. Pseudocode

FUNCTION simulate_atm(balance, transactions):
    FOR EACH (id, type, amount) IN transactions:
        IF amount <= 0 THEN REJECT
        ELSE IF type == 'DEPOSIT' THEN balance += amount
        ELSE IF type == 'WITHDRAWAL' THEN
            IF amount > MAX_SINGLE OR daily_sum + amount > DAILY_LIMIT OR balance - amount < MIN_BAL THEN
                REJECT
            ELSE
                balance -= amount; daily_sum += amount
        PRINT audit row
END FUNCTION

def parse_time_to_minutes(time_str):
    """Converts 'HH:MM' 24-hour time format string into total minutes from midnight."""
    parts = time_str.split(":")
    hours = int(parts[0])
    minutes = int(parts[1])
    return hours * 60 + minutes


def minutes_to_time_str(total_minutes):
    """Converts total minutes back into formatted 'HH:MM' string."""
    hours = total_minutes // 60
    mins = total_minutes % 60
    return f"{hours:02d}:{mins:02d}"


def detect_shift_conflicts(shift_roster):

2. Objectives

1. Process batch records containing total produced and defective units.
2. Compute component pass counts, defect percentages, and yield rates.
3. Categorize batches: Grade-A (<=1.5%), Grade-B (<=3.5%), Quarantined (>3.5%).

3. Assumptions & Constraints

1. Defective units cannot exceed produced units.
2. Standard allowable defect threshold is 3.50%.

4. Step-by-Step Algorithm

1. Initialize factory totals for produced, passed, and defective.
2. For each batch (batch_id, product, produced, defective): passed = produced - defective; defect_pct = (defective/produced)*100; yield_pct = (passed/produced)*100.
3. Check defect_pct against 1.5% and 3.5% thresholds. Assign status Grade-A, Grade-B, or Quarantined.
4. Aggregate totals, calculate overall factory defect and yield rates.
5. Output full quality matrix and quarantine action list.

5. Pseudocode

FUNCTION analyze_quality(batches, threshold):
    FOR EACH (id, name, produced, defective) IN batches:
        passed = produced - defective
        defect_pct = (defective / produced) * 100
        yield_pct = (passed / produced) * 100
        IF defect_pct <= 1.5 THEN status = 'GRADE-A'
        ELSE IF defect_pct <= threshold THEN status = 'GRADE-B'
        ELSE status = 'QUARANTINED'
    PRINT factory audit table and quarantined lines
END FUNCTION

def analyze_manufacturing_quality(batch_records, defect_threshold_pct):
    print("=" * 95)
    print("        PRECISION AUTOMOTIVE MANUFACTURING - QUALITY CONTROL MATRIX")
    print(f"        Standard Defect Tolerance Threshold: {defect_threshold_pct:.2f}%")

    total_units_produced = 0
    total_units_passed = 0
    total_defective_units = 0

    quarantined_batches = []
    approved_batches = []

    # Process nested batch records: (batch_id, product_name, units_produced, defective_units)
    for record in batch_records:
        batch_id, product_name, produced, defective = record

        passed = produced - defective
        defect_pct = (defective / produced) * 100.0 if produced > 0 else 0.0
        yield_pct = (passed / produced) * 100.0 if produced > 0 else 0.0

        total_units_produced += produced
        total_units_passed += passed
        total_defective_units += defective

        # Quality Threshold Verification
        if defect_pct <= 1.5:
            status = "GRADE-A (PASS)"
            approved_batches.append(batch_id)
        elif defect_pct <= defect_threshold_pct:
            status = "GRADE-B (ACCEPTABLE)"
            approved_batches.append(batch_id)
        else:
            status = "QUARANTINED (FAIL)"
            quarantined_batches.append((batch_id, product_name, defect_pct, defective))

        print(f"{batch_id:<9} {product_name:<18} {produced:<10} {passed:<9} {defective:<11} {defect_pct:<11.2f} {yield_pct:<10.2f} {status}")

    overall_defect_pct = (total_defective_units / total_units_produced) * 100.0

    print(f"Overall Factory Defect Rate   : {overall_defect_pct:.2f}%")
    print(f"Overall Factory Yield Rate    : {overall_yield_pct:.2f}%")

    print("\n" + "=" * 95)
    print("                     FLAGGED BATCHES REQUIRING REWORK")
    print("=" * 95)
    if quarantined_batches:
        print(f"{'BatchID':<10} {'Product Line':<22} {'Defect Rate':<14} {'Defective Units':<16} {'Mandatory Action'}")
        print("-" * 95)
        for q in quarantined_batches:

            print(f"{b_id:<10} {p_name:<22} {d_rate:<14.2f}% {d_units:<16} Immediate Line Stoppage & Root Cause Analysis")
